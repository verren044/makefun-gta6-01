Solmar Bay — a complete open-world crime game in the spirit of GTA 6, built from scratch in plain JavaScript and canvas. A 3600×2800 city with five districts including the new Ember Heights (Ember Volcano, Ember Casino, its own street grid and park), twelve drivable cars headed by the 640-top-speed Ember GT, twenty-two traffic cars, forty pedestrians, carjacking, a five-star wanted system with cop cars and on-foot cops, combat, a HUD with a live minimap and district readout, a save (v2), and an eight-mission story worth $5,500 — from First Wheels to the Ember Score.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. WASD / arrows to move and drive, E to enter a car, J to shoot, P to pause, S to save from the pause screen.
